AiderLog v69 배포 확인

1. 이 폴더의 내용 전체를 Vercel 프로젝트 루트에 배포합니다.
2. Vercel Root Directory는 비워 둡니다.
3. Deployments에서 새 v69 배포를 Production으로 승격합니다.
4. 아래 주소를 엽니다.
   https://aiderdear1.vercel.app/sw.js
5. 첫 줄이 아래와 같아야 합니다.
   const CACHE='aiderlog-v69-language-lab-task-desk';

첫 줄에 이전 버전이 보이면 코드는 새로 올라갔더라도 운영 주소가 아직 이전 배포를 가리키는 상태입니다.
이 경우 Vercel Deployments에서 최신 배포의 메뉴를 열어 Promote to Production을 선택하세요.

정상 동작
- https://aiderdear1.vercel.app/ → AiderLog SCHEDULE 첫 화면
- ROUTINE → 아래로 전환 → 메인 프레임 안에 LANGUAGE LAB
- PAPER 다음 → 노란색 TASK 탭
- ROUTINE 탭에서 아래로 화면 전환 → 어학 학습
- /language-study/를 단독으로 열기 → AiderLog 첫 화면으로 자동 복귀
- ROUTINE에서 화면 전환 → AiderLog 프레임 내부 다국어 학습 표시
