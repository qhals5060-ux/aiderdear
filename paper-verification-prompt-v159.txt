방금 생성한 AiderLog JSON을 첨부된 논문 원문과 다시 대조하여 검증하라.

이번 작업의 목적은 내용을 더 풍부하게 만드는 것이 아니라 잘못된 내용, 과도한 해석, 누락된 근거를 찾아 수정하는 것이다.

다음을 집중적으로 검사하라.

- 제목, 저자, 연도, DOI
- 표본 크기와 집단별 인원
- 연구 설계와 측정 시점
- 포함·제외 기준
- 변수의 역할
- 개념의 논문 내 정의
- 조작적 정의와 측정 도구
- MRI·인지검사·임상척도 정보
- 효과크기, 신뢰구간, p값
- 보정 전 결과와 보정 후 결과
- 유의한 결과와 유의하지 않은 결과
- 표·그림 번호
- 원문 인용과 위치
- 저자의 주장과 AI 해석의 구분
- 상관관계를 인과관계로 표현한 부분
- 횡단 결과를 변화나 예측으로 표현한 부분
- 원문에 없는 일반화
- 원문으로 확인할 수 없는 비판적 평가

검증 규칙:

1. 원문으로 확인되지 않는 내용은 삭제하거나 null로 변경한다.
2. 위치를 확인할 수 없는 페이지·표·그림 번호는 추측하지 않는다.
3. 문맥에서 추론한 개념은 inferredFromContext를 true로 표시한다.
4. 신뢰도가 과도하게 높게 표시된 항목을 수정한다.
5. 그림이나 표를 판독할 수 없으면 visualReadable을 false로 변경한다.
6. 누락된 핵심 개념·비유의 결과·주요 한계가 있으면 추가한다.
7. 원문 인용은 실제 문장과 일치하는지 확인한다.
8. JSON 문법과 ID 참조 관계를 검사한다.
9. 수정 이유는 verificationSummary에 요약하되 JSON 밖에는 작성하지 않는다.

최종 출력은 수정이 완료된 aiderlog.paper.v2 JSON 하나만 출력하라.
Markdown 코드 블록이나 설명 문장은 출력하지 마라.
