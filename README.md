# AiderDear v38

둘만의 일정, 감정 기록, 사진·동영상, 이벤트, 여행, PRIVATE 루틴을 한곳에서 관리하는 정적 웹앱입니다.

## 실행

이 폴더 전체를 정적 웹 호스팅에 올리세요. 로컬 확인은 폴더 안에서 간단한 HTTP 서버를 실행한 뒤 브라우저로 접속하면 됩니다. Google 로그인과 설치형 앱(PWA)은 `file://`로 직접 열 때가 아니라 HTTPS 또는 localhost 환경에서 동작합니다.

## Google 연결

1. Google Cloud Console에서 OAuth 2.0 웹 클라이언트를 만듭니다.
2. 실제 사이트 주소를 승인된 JavaScript 원본에 등록합니다.
3. OAuth 앱이 테스트 상태라면 `OAuth 동의 화면 → 대상 → 테스트 사용자`에 함께 사용할 상대의 Google 이메일을 추가합니다.
4. 관리자가 앱에 로그인한 뒤 관리자 모드에서 같은 이메일을 구성원으로 등록하고 저장합니다. 저장 즉시 공용 Drive와 Calendar 접근 권한이 갱신됩니다.
5. `상대 초대 링크 복사`를 눌러 링크를 상대에게 보냅니다. 상대 브라우저는 링크에서 공용 OAuth 설정을 불러오므로 클라이언트 ID를 다시 입력할 필요가 없습니다.
6. 상대가 받은 링크에서 Google 로그인 후 Calendar와 Drive 권한을 허용합니다.

## 개인 모드와 커플 연결

- 로그인 직후 기본 상태는 개인 모드입니다. 다른 사용자를 등록했더라도 서로 선택하기 전에는 기록이 공유되지 않습니다.
- 두 사용자가 로그인 창의 `연결 상대`에서 서로를 선택하고 저장해야 상호 연결이 성립합니다.
- 상호 연결 후에는 SCHEDULE, EMOTION, RECORD, EVENT의 기록과 앨범, D-day, 버킷리스트, 대표 미디어 및 우편이 현재 커플 범위에서 공유됩니다.
- PRIVATE의 메모, 체크리스트, 루틴은 언제나 본인 Google Drive의 별도 폴더에 저장되며 공유 대상에서 제외됩니다.
- 연결 상대를 `개인 모드`로 바꾸면 상대 기록과 우편이 즉시 화면에서 사라지고, 본인이 소유한 AiderDear Calendar와 감정 폴더에서 이전 상대의 권한이 회수됩니다.
- 관리자 계정은 OAuth 설정과 로그인 허용 목록만 관리합니다. 콘텐츠 열람 권한은 다른 계정과 동일하며 관리자 우회가 없습니다.
- v36 이전의 앨범·대표 미디어·D-day 데이터는 첫 로그인 시 현재 개인 또는 상호 연결 공간으로 자동 이전됩니다.

사용자 기록은 별도 서버가 아니라 연결한 Google Calendar와 Google Drive에 저장됩니다. 초대 링크에는 비밀번호나 OAuth 비밀키가 아니라 공개 설정인 웹 클라이언트 ID와 관리자 이메일만 포함됩니다. 운영 전에는 OAuth 동의 화면과 승인된 도메인 설정을 확인하세요.

## 포함 파일

- `index.html` — 전체 화면과 기능
- `manifest.webmanifest` — 설치형 앱 정보
- `sw.js` — 오프라인 앱 셸 캐시
- `aiderdear-icon.svg`, `aiderdear-icon-*.png` — 앱 아이콘
- `aiderdear-sky.jpg` — 배경 이미지
- `업데이트_내용.txt` — 개선 내역
